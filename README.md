# MIZUNE UHD — Sound Visual Laboratory

マイクまたは音楽ファイルを読み込み、水・紙・ガラス・植物を基調とした2Dアニメーションへ変換するローカルファーストWebアプリです。

## 起動方法（Windows）

1. ZIPを展開します。
2. `start_windows.bat` をダブルクリックします。
3. 自動的に選択されたlocalhostのURLがブラウザで開きます。

Pythonが入っていない場合は、任意の静的Webサーバーでこのフォルダーを配信してください。マイク機能はブラウザの安全制限により、HTTPSまたはlocalhost環境でのみ動作します。

## 超高解像度版の変更点

初期設定は「超高解像度」です。

- Canvas内部解像度を端末DPRとスーパーサンプリングから計算
- 最大描画倍率4倍
- 最大内部画素数約18メガピクセル
- 1920×1080のPC表示では最大3840×2160相当で描画
- 高密度スマートフォンでは画面の実画素に近い内部解像度を使用
- FFTを最大8192点へ拡張
- 円形スペクトラム最大144本前後
- 波形線、背景水面、紙の帯、植物、粒子の描画間隔を細分化
- 分析画面の全体波形も高DPI化
- 設定パネルに内部解像度、メガピクセル、FPSを表示

端末負荷が高い場合は、表現設定の「描画解像度」を「高解像度」または「自動」へ変更してください。超高解像度では発熱と電池消費が増える可能性があります。

## 実装済み

- マイク入力とリアルタイム解析
- 音楽ファイルの複数読み込み、再生、シーク、プレイリスト
- 8種類のCanvas 2Dビジュアルモード
- 波形、円形スペクトラム、粒子、水面、紙、ガラス、植物表現
- 音量連動背景
- MediaRecorderによる録音とブラウザ内保存
- Web Workerによる全体波形・無音・音量・音域区間分析
- IndexedDBライブラリ
- 設定の保存・書き出し・読み込み
- 描画解像度3段階、自動品質調整、動きを減らす設定
- PWA / Service Worker

## 注意

- 対応音声形式と録音形式はブラウザに依存します。
- タブがバックグラウンドになると、ブラウザが描画頻度を下げます。
- 区間分析は医療・音響測定機器ではなく、視覚化のためのヒューリスティック分析です。
- IndexedDBの保存データは、ブラウザのサイトデータ削除により消える場合があります。
- 18MPは安全上限であり、画面サイズと端末DPRに応じて実際の内部解像度は変わります。

## 旧版から更新する場合

旧版をPWAとして開いたことがある場合は、ブラウザを完全に閉じて再度開くか、サイトデータ／キャッシュを削除してから本版を起動してください。Service Workerのキャッシュ世代はv1.1.0へ更新済みです。
